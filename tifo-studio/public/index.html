    Workflow
    1. Write the script → split into scenes.
    2. Record/upload voiceover per scene, “Fit to audio”.
    3. Place players (formations), move the playhead, drag players to keyframe motion.
    4. Add arrows / zones / labels timed to the words.
    5. Drag a camera frame to zoom in.
    6. Export video.
